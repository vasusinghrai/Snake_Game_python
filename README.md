 A classic Snake Game developed using Python's Turtle graphics module.

##  Features

- Keyboard-controlled snake
- Random food generation
- Score tracking
- Collision detection
- Game-over system
- Smooth game movement

##  Technologies Used

- Python
- Turtle
- Time
- Random
